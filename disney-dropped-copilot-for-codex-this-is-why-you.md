# Disney Dropped Copilot For Codex This Is Why You Should Too

Every figure, date, name and claim stated in this video, with where it comes from.

## The reported change

**Disney is removing GitHub Copilot from its approved AI coding tool list for US
technology staff in August 2026, and adding OpenAI Codex.**
Reported by Business Insider on 29 July 2026, from an internal message viewed by the
outlet and from eight Disney technology employees who spoke to it.
Source: Business Insider, "Disney is ditching Microsoft's GitHub Copilot and adding
OpenAI's Codex", 29 July 2026.

**Four tools leave the approved list: GitHub Copilot, Kiro, Amazon Q, and Claude accessed
through AWS Bedrock.**
Same report. Claude access via AWS Bedrock ends; the Claude model itself remains available
to Disney through a different route.
Source: Business Insider, 29 July 2026.

**Two tools are retained: Claude Enterprise and Cursor.**
Same report.
Source: Business Insider, 29 July 2026.

**The internal message was delivered on 29 July 2026.**
Source: Business Insider, 29 July 2026.

**The change applies to US technology staff only. International operations are
unaffected.**
Source: Business Insider, 29 July 2026.

**No availability date was given for Codex.**
The report states Disney had not disclosed when Codex would become available.
Source: Business Insider, 29 July 2026.

**Eight Disney technology employees spoke to the outlet.**
Source: Business Insider, 29 July 2026.

**A product manager described Copilot's output as coming back "needlessly complex" and
needing cleanup. A longtime engineer said his own access lapsed from disuse.**
Both are quotes and paraphrases carried in the same report.
Source: Business Insider, 29 July 2026.

**No benchmark accompanied the decision.**
The reporting describes usage and developer preference as the basis. No published
benchmark comparison is cited in it.
Source: Business Insider, 29 July 2026.

Caveat carried on screen: this is reporting from an internal message and employee
interviews, not a public announcement by the company.

## The tools named

**GitHub Copilot Business costs $19 USD per granted seat per month. GitHub Copilot
Enterprise costs $39 USD per granted seat per month.**
Source: GitHub Docs, "Plans for GitHub Copilot",
https://docs.github.com/en/copilot/get-started/plans

**GitHub Copilot in 2026 includes an autonomous coding agent, multi file edits, agentic
code review and a choice of models.** The coding agent "can research a repository, create
an implementation plan, and make code changes on a branch", works "independently in the
background to complete tasks, just like a human developer", has "its own ephemeral
development environment, powered by GitHub Actions", and can open a pull request.
Source: GitHub Docs, "About Copilot coding agent",
https://docs.github.com/en/copilot/concepts/agents/coding-agent/about-coding-agent

**OpenAI Codex is a coding agent that takes a task, works on a repository and returns a
change to review.** Codex cloud gives "longer tasks dedicated environments" and lets you
"open a pull request when the result is ready" after reviewing the summary and diff. It is
also available as a CLI ("Inspect, edit, and automate from the terminal"), an IDE
extension ("Work with Codex beside the code in your editor"), a desktop app and on the
web.
Source: OpenAI Codex documentation, https://learn.chatgpt.com/docs/cloud

**Kiro is an agentic development tool built and operated by AWS, organised around specs.**
It is "an agentic AI with an IDE, CLI, and web interface", and it "turns your prompts into
requirements, architectural designs, and sequenced tasks, then implements them with
parallel agents". AWS describes it as "Built and operated by AWS".
Source: Kiro, https://kiro.dev/

**Amazon Q Developer is AWS's broader generative AI assistant, spanning code and the
console.** AWS describes it as an assistant that helps "understand, build, extend, and
operate applications and workloads on AWS", available in the IDE and in the AWS Management
Console.
Source: AWS, Amazon Q Developer, https://aws.amazon.com/q/developer/

**AWS Bedrock is a route to third party models rather than a model itself.** Claude is one
of the models offered through it, which is why ending Bedrock access changes the route
without removing the model.
Source: AWS, Amazon Bedrock, https://aws.amazon.com/bedrock/

**Cursor is an AI code editor.**
Source: Cursor, https://cursor.com/

## What is not established

- Disney has not published a statement confirming the change. Everything above about
  Disney rests on one outlet's reporting from an internal message and employee interviews.
- Eight employees is a small number of voices from a large technology organisation, and
  their accounts describe their own usage rather than measured company wide telemetry.
- No usage figures, licence counts or costs specific to Disney have been published, so the
  per seat pricing above is GitHub's list price and not a statement about what Disney paid.
- The date Codex becomes available to Disney staff is unknown.
- Whether Codex performs better than the tools being removed, inside Disney or anywhere
  else, is not established by any of the above.
